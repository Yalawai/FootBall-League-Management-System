
# ⚽ Football League Management System

## 🔧 Features

- **Team Management** – Create, update, and delete team profiles.
- **Player Management** – Add players to teams and manage player data.
- **Match Scheduling** – Schedule matches between teams with date and time.
- **User Interface** – Interactive React frontend for smooth navigation.
- **REST API** – Django REST Framework API for data operations.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML, CSS
- **Backend:** Django, Django REST Framework
- **Database:** SQLite (for development)
- **Version Control:** Git

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Yalawai/FootBall-League-Management-System.git
cd FootBall-League-Management-System
```bash

### 2. Running a Backend Django Server
```bash
cd backend
python -m venv env
source env/bin/activate  # For Windows: env\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```bash

### 3. Frontend React Server
```bash
cd frontend
npm install
npm run dev
```bash
